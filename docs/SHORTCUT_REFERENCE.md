# Keyboard shortcuts

_Generated from `src/renderer/app/shortcuts.ts`. Run `UPDATE_DOCS=1 npx vitest run tests/unit/docs.test.ts` after changing it._

Simple Cell follows Microsoft Excel’s shortcuts (from Microsoft’s “Keyboard shortcuts in Excel” pages for Windows and Mac). Linux uses the Windows keys. Every shortcut can be changed in **Help → Shortcuts**. The **Google Sheets** preset (Settings → Keyboard) switches the ones that differ.

## Reserved by the operating system

These keys never reach Simple Cell:

| Keys | System | Note |
|---|---|---|
| `Ctrl+Alt+Delete` | Windows | Security screen |
| `Alt+F4` | Windows/Linux | Closes the window (Simple Cell asks to save first) |
| `⌘H` | macOS | Hides the app: use Ctrl-H for Replace on macOS, as in Excel for Mac |
| `⌘Space` | macOS | Spotlight: select the column with Ctrl-Space |
| `⌃+Alt+Arrow` | Linux (GNOME) | Switches workspaces |
| `⌃+Alt+F1…F12` | Linux | Switches virtual terminals; use the Formulas tab for Calculate All |
